# Security Policy

## Scope

Naratama Gelanggang is an offline-first desktop application that stores career saves locally in SQLite files and does not transmit telemetry or require network accounts.

## Reporting a Vulnerability

If you discover a security issue (for example: path traversal in save archive import/export, SQL injection in IPC commands, or unsafe WebView behavior):

1. **Do not** open a public issue with exploit details.
2. Report the vulnerability privately to the repository maintainers with:
   - Affected file(s) and version/commit
   - Reproduction steps or proof of concept
   - Impact assessment and suggested remediation (if available)

We will acknowledge reports promptly and prioritize fixes for any confirmed vulnerabilities.
