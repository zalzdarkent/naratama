1. BUG KRITIS & TINGGI (CRITICAL / HIGH)
================================================================================

[H-01] Nama Tim Home & Away Tertukar di Match Replay Saat User Main Tandang (Away)
- Lokasi : desktop/src/components/MatchReplay.tsx (baris 100-101)
- Bukti  :
    const teamName = (side: string) =>
      (normalize(side) === 'home') === userIsHome ? replay.home_name : replay.away_name;
- Dampak : Jika klub user bermain sebagai tim tandang (userIsHome === false),
           setiap event dari tim 'home' justru menampilkan nama tim 'away' dan
           sebaliknya. Gol/kartu/cedera tercatat ke tim yang salah di feed replay.
- Saran  : Ubah langsung menjadi `normalize(side) === 'home' ? replay.home_name : replay.away_name`.

[H-02] Label Badge "International" Salah Sasaran di Dropdown Kompetisi
- Lokasi : desktop/src/components/CompetitionPanel.tsx (baris 216)
- Bukti  : `{name} {org >= 3 ? `· ${t.competition.international}` : ''}`
- Dampak : Di Rust (`naratama-model/src/enums.rs`), enum `TournamentOrg` adalah:
           1 = League, 2 = International, 3 = NationalCup, 4 = Friendly.
           Akibatnya Piala Domestik (3) dan Friendly (4) dilabeli "International",
           sedangkan kompetisi International sebenarnya (2) tidak mendapat label.
- Saran  : Ubah kondisi menjadi `org === 2`.

[H-03] Fitur Impor Save Archive Tidak Bisa Dijalankan Jika Hanya Ada 1 File Archive
- Lokasi : desktop/src/components/StartScreen.tsx (baris 31, 61, 121-122, 338-352)
- Bukti  : State `archive` diinisialisasi `""`. Saat `listSaveExports()` mengembalikan
           daftar file, `setArchives(...)` dipanggil tapi `setArchive(list[0])` TIDAK
           pernah dipanggil.
- Dampak : Dropdown secara visual menampilkan file archive pertama, tetapi state
           `archive` tetap kosong `""`. Tombol Impor diam-diam gagal / tidak merespons
           jika user tidak mengganti pilihan dropdown terlebih dahulu (dan mustahil
           diganti jika hanya ada 1 file archive).
- Saran  : Set `setArchive((cur) => cur || (list[0] ?? ''))` setelah `listSaveExports()`.

[H-04] Menekan Spasi / Escape Saat Live Match Menghancurkan Sesi Match Tanpa Cleanup
- Lokasi : desktop/src/App.tsx (baris 329-344, 1623) & LiveMatchPanel.tsx (baris 190)
- Bukti  : Shortcut `Space` memanggil `setLive(null)` lalu langsung memicu
           `handlePlayMatchday()` baru; tombol `Abandon` dan `Escape` hanya memanggil
           `setLive(null)` di React tanpa memberi tahu backend Tauri.
- Dampak : User yang tidak sengaja menekan Spasi saat Live Match akan langsung
           menutup pertandingan berjalan dan men-trigger sesi baru/error state di
           backend, sedangkan Abandon tidak mengonfirmasi atau membersihkan sesi live.
- Saran  : Blokir shortcut `Space` saat `live !== null`, tambahkan konfirmasi pada
           Abandon, dan sediakan/panggil command backend untuk membatalkan live match.

[H-05] Menerima Tawaran Manajer (Manager Offer) Tidak Me-refresh Dashboard & Klub
- Lokasi : desktop/src/App.tsx (baris 623-636)
- Bukti  : Callback tombol Terima hanya memanggil `notify(t.manager.accepted); setManagerOffer(null);`
           tanpa memanggil `refresh()`.
- Dampak : Setelah user menerima tawaran pindah klub, seluruh UI masih menampilkan
           klub lama, skuad lama, anggaran lama, dan klasemen liga lama sampai user
           melakukan aksi lain yang memicu `refresh()`.
- Saran  : Panggil `return refresh();` setelah `respondManagerOffer(offer_id, true)`.

[H-06] Live Match: Tidak Bisa Kembali ke Mentalitas "Balanced" Setelah Mengubahnya
- Lokasi : desktop/src/components/LiveMatchPanel.tsx (baris 224)
- Bukti  : `disabled={busy || (pending.length === 0 && mentality === 'balanced')}`
- Dampak : Jika user mengganti mentalitas ke `attacking` atau `defensive` lalu klik
           Terapkan, kemudian ingin kembali ke `balanced` tanpa melakukan pergantian
           pemain, tombol Terapkan terkunci (disabled).
- Saran  : Simpan state `appliedMentality` dan disable hanya jika
           `pending.length === 0 && mentality === appliedMentality`.

[H-07] Klik Pemain Lawan di TeamDetailModal Tidak Melakukan Apa-Apa (Dead Click)
- Lokasi : desktop/src/App.tsx (baris 1595-1598) & TeamDetailModal.tsx (baris 110, 130)
- Bukti  : `onOpenPlayer` mencari `squad.find((p) => p.player_id === id)` — padahal
           `squad` hanya berisi pemain klub user sendiri!
- Dampak : Baris pemain di modal profil klub lawan memiliki `cursor: pointer`, tetapi
           saat diklik tidak membuka detail pemain di Inspektor maupun modal apa pun.
- Saran  : Kirim objek `PlayerDto` langsung dari `TeamDetailModal` ke `setSelectedPlayer(p)`
           (dan tutup modal atau tampilkan profil pemain lawan di Inspektor).

[H-08] TeamDetailModal Terjebak di Layar "Memuat..." Tanpa Tombol Tutup & Kebal Escape
- Lokasi : desktop/src/components/TeamDetailModal.tsx (baris 45-47) & App.tsx (baris 338-343)
- Bukti  : Terverifikasi langsung oleh Playwright (`01b-team-detail-modal`:
           `teamModalButtons: 0`, `teamModalClosedOnEsc: false`).
- Dampak : Jika `getTeamDetail` gagal/lambat/null (mis. preview mode atau error DB),
           modal tidak memiliki tombol Tutup sama sekali dan tidak bisa ditutup dengan
           tombol `Escape` (begitu juga `MatchStatsModal` dan `DossierModal`).
- Saran  : Tambahkan tombol Tutup di state loading/error modal, dan tambahkan
           `setTeamId(null); setStats(null); setDossier(null);` di handler `Escape`.

[H-09] Hapus Save Slot Tidak Ada Konfirmasi (Penghapusan Permanen Sekali Klik)
- Lokasi : desktop/src/components/StartScreen.tsx (baris 149-160, 305-311)
- Bukti  : Tombol `Hapus` langsung memanggil `desktopApi.deleteSaveSlot(slot.slot_index)`.
- Dampak : Satu klik tidak sengaja langsung menghapus permanen file save karier multi-musim.
- Saran  : Tambahkan modal konfirmasi atau 2-step confirm ("Yakin Hapus?").

  2) Teks petunjuk tertulis "Klik dua pemain (di lapangan atau tabel) untuk menukar

[M-02] Topbar Meluap / Terpotong pada Resolusi Minimum 1024x680
- Lokasi : desktop/src/styles/theme.css (baris 45-62)
- Bukti  : Terverifikasi oleh Playwright (`11a-dashboard-1024` & `11b-clubHub-1024`:
           `topbarOverflow: true`).

- Saran  : Gunakan `grid-template-rows: auto 1fr;` dengan `min-height: 58px` pada `.topbar`
           atau padatkan padding/label pill pada media query `max-width: 1200px`.

[M-05] Shortcut Keyboard "0" untuk Menu ke-10 ("Berita Dunia") Rusak
